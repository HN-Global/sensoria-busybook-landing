**목적** 인스타·광고에서 넘어온 사람을 비공개 3종 세트 패키지(144,000원)까지 데려가는 것
**현재 상태** 뼈대(프레임)만 올려둔 상태. 사진·영상이 들어갈 자리를 네모로 비워 두었습니다.

## 작업 방법 (디자이너)

### 1. 받아오기

처음 한 번만. 먼저 누가 고쳤는지 기록될 이름을 등록합니다 (이거 안 하면 커밋이 거부됩니다).

```bash
git config --global user.name "정주혜"
git config --global user.email "깃허브에_등록한_이메일"
```

그다음 내려받습니다.

```bash
git clone https://github.com/HN-Global/sensoria-busybook-landing.git
cd sensoria-busybook-landing
```

그 뒤로는 작업 시작할 때마다 **먼저** 이걸 돌립니다. 남이 고친 걸 받아오는 겁니다.

```bash
git pull
```

### 2. 고치기

`index.html` 한 파일에 전부 들어 있습니다. 브라우저로 그 파일을 열면 바로 보입니다.
(서버를 켜거나 빌드할 필요 없습니다.)

### 3. 올리기

```bash
git add -A
git commit -m "무엇을 바꿨는지 한 줄"
git push
```

**push 하면 1~2분 안에 자동으로 올라갑니다.** 따로 배포할 게 없습니다. 올라간 결과는 위 두 주소에서 바로 보입니다.

## 이 페이지에 들어가는 자리

`index.html` 안에 블록 8개가 `<!-- 1 -->` ~ `<!-- 8 -->` 주석으로 번호 붙어 있습니다.
각 블록 오른쪽 회색 칸(`.note`)은 **왜 그 자리에 그게 들어가는지 적어 둔 메모**입니다. 실제 페이지에는 나가지 않습니다.

| 블록 | 화면 | 필요한 것 |
|---|---|---|
| 01 | 테마별 제품샷 | 제품컷 **3장** — 프린세스 / 오션 / 정글. 같은 각도·같은 조명 |
| 02 | 내 아이를 위한 특별한 선물 | 감성컷 **1장** — 아이와 부모가 함께 있는 장면, 표정이 주인공 |
| 03 | 아이가 노는 영상 | **세로 영상 2개** — 몰입하는 장면 / 혼자 해내는 장면 |
| 04 | 패키지 · 제품 사진 | **4장** — 박스 외관 / 열었을 때 / 펼친 모습 / 바느질·펠트 단면 |
| 05 | 리뷰 · 와디즈 · 언론 | 썸네일 **3장** |
| 06 | 할인 · 비공개 · 재고 | 없음 (텍스트·숫자) |
| 07 | 연령대별 안내 | 사진 **2장** — 부모와 함께 / 혼자 노는 모습 |
| 08 | 안전성 인증 | **KC 마크** |

**구매 버튼이 가는 곳** `https://sensoria.kr/shop_view?idx=28` (3종 세트 · 144,000원)
이 링크에는 **UTM 을 붙이지 않습니다.** 붙이면 방문 분석이 세션을 끊어 랜딩에서 구매까지가 한 줄로 안 이어집니다.

영상은 세로(9:16)입니다. 자동재생·음소거로 들어가니 **소리 없이도 무슨 장면인지 보여야** 합니다.

## 실제 랜딩으로 바꿀 때 할 일

지금은 설계도 상태라 일부러 미뤄둔 것들이다. 디자이너 작업이 끝나 진짜 랜딩이 되면 **한 번에** 처리한다.

| 할 일 | 내용 |
|---|---|
| **색인 열기** | `robots` 를 `index, follow` 로. 지금은 설계도라 닫아 뒀다 |
| **제목·설명 교체** | `<title>` 이 `비지북 세트 랜딩 프레임` 이다. 색인되면 이게 검색 결과 제목이 된다 |
| **구글 소유확인** | `google-site-verification` 메타가 없다. 지표 세션이 센소리아 전용 값을 준다 (전에 들어 있던 건 SHL 값이라 뺐다) |
| **`scroll_depth`** | 루딕스 `rdx-track.js` 와 **이름·단계 똑같이** — 1/10/25/50/75%, 페이지당 각 1회 |
| **`hero_view`** | 첫 화면 실노출. 백그라운드 탭에서 로드만 된 경우는 제외 |
| **`product_slug`** | 커스텀 이벤트마다 얹는다. 값은 **`busybook-set3`** |

설계도 상태의 스크롤 데이터는 실제 페이지와 비교가 안 되므로 지금 모아도 못 쓴다. 그래서 미뤘다.

**GA4 linker 는 걸지 않는다.** `start.sensoria.kr` 과 `sensoria.kr` 은 등록가능도메인이 같아 `.sensoria.kr` 쿠키를 공유한다. 세션이 이미 이어지는 것을 확인했다. linker 를 걸면 주소에 `_gl` 만 붙고 얻는 게 없다.

바꾸고 나면 **지표 세션에 알린다.** 구글·네이버·다음 등록과 sitemap/rss 제출을 그쪽에서 한다.

## 건드리지 말아 주세요

`index.html` 맨 아래 **계측 코드 한 덩어리**와 `<head>` 안의 아래 줄들은 손대지 말아 주세요. 지우면 광고 성과를 아예 못 보게 됩니다.

| 줄 | 무엇 |
|---|---|
| `robots` = `noindex, follow` | **일부러 닫아 둔 것.** 지금은 설계도라 검색에 걸리면 안 됩니다. 실제 랜딩으로 바뀔 때 엽니다 |
| `google-site-verification` / `naver-site-verification` | 검색엔진 소유확인. 지우면 다시 등록해야 합니다 |
| `canonical`, `og:` 들 | 링크 공유될 때 보이는 제목·그림 |
| 맨 아래 `<script>` 한 덩어리 | GA4 · Clarity · 메타 픽셀 |

루트의 `robots.txt`, `sitemap.xml`, `rss.xml`, `favicon.ico`, `icon-512.png`, `apple-touch-icon.png`, `og.jpg` 도 지우지 말아 주세요.
