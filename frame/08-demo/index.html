연령 블록 — 고르실 것 두 가지

사장님이 물어보신 두 가지를 실제 화면으로 만들어 놨습니다. 하나는 나이를 어디까지 적을지, 하나는 칸에 뭘 넣을지입니다. 각 안을 눈으로 비교하시고 하나씩 골라 주시면 바로 기획 프레임에 넣겠습니다.

먼저 알아야 할 것 — 와디즈 보정 사진 149장을 전부 봤습니다.

아이가 나온 컷은 전부 같은 아이 한 명입니다. 옷도 같고(흰 민소매에 연두 바지) 머리도 같습니다. 하루에 몰아서 찍은 사진입니다. 나이는 보기에 다섯 살 안팎 한 명뿐입니다.

그래서 실사로 세 연령대를 보여주는 건 지금 가진 사진으로는 불가능합니다. 세 칸에 같은 아이를 넣으면 보는 사람이 바로 알아챕니다. 대신 장소는 셋(책상·침대·바닥)이고 어른 손이 같이 들어온 컷도 있어서, 나이 대신 「노는 방식」으로 세 칸을 나누면 지금 사진으로 됩니다.
